ROBLOX / VERCEL

Estrutura pronta para Vercel.

1. Suba TODOS estes arquivos para a raiz do repositório GitHub.
2. Importe o repositório na Vercel.
3. Em Settings > Environment Variables, crie:
   ROBLOX_USERNAME = pedromadara173
   INITIAL_ROBUX = 567890
4. Faça Redeploy após adicionar as variáveis.

Rotas:
/                     -> robuxcomprar.html
/pt/robuxcomprar.html -> robuxcomprar.html
/api/local-user      -> API
/api/roblox-users    -> API

Não envie o arquivo .env real para o GitHub.
